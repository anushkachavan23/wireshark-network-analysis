# Wireshark Network Analysis 🔎

## 🎯 Objective
To capture, analyze and understand network traffic using Wireshark.

## 🛠️ Tools Used
- Wireshark
- Kali Linux
- TCP/IP

## 🔍 Topics Covered
- Source and Destination IP addresses
- TCP and UDP traffic
- DNS packets
- Network protocols
- Packet filtering
- I/O Graph

## 🔎 Wireshark Filters

```text
ip.addr == 192.168.1.1
tcp
udp
dns
http
```
